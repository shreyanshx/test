QUESTIONS & ANSWERS

Frequently Asked Questions

Clear answers to common questions about setting up and operating TestPaper.

How does professor authentication gating work? ➕
When the deployment sets the optional PROF_SIGNUP_CODE secret, anyone attempting to register as a professor must supply the matching secret code. Students can register freely without needing any code.
How is brute-force password guessing prevented? ➕
TestPaper implements sliding-window login throttling. After 5 consecutive failed attempts from an email/IP pair within 15 minutes, access is locked out for 15 minutes and returns HTTP 429 with a Retry-After header.
Can students see correct answers before submitting? ➕
No. The backend API strictly strips all correct answer fields whenever a paper is requested by a user with the student role. Answers are only verified server-side inside the Worker during submission grading.
What database does TestPaper use? ➕
TestPaper runs on Cloudflare Workers backed by SQLite inside Durable Objects for zero-setup deployments, with full ACID compliance and zero external database management needed.
